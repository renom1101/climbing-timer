Climbing Timer Help

Climbing Timer is designed for climbing competitions, competition simulations, and similar sessions. It follows official IFSC timing guidance.

Start and stop

  • Press Start to begin.
  • Press Stop to pause.
  • Press Start again to continue.
  • Press Reset to return to the full climbing time.

How the timer runs

  • The timer counts down the climbing time.
  • If Preparation time is on, a preparation phase follows each climb.
  • The timer keeps looping through the phases until you stop it.
  • Controls fade while the timer is running. Move the mouse or tap the screen to show them again.

Timer settings

  • Preparation time turns the prep phase on or off.
  • Climbing seconds sets the climbing phase length.
  • Preparation seconds sets the preparation phase length.

You cannot change timing settings while the timer is running.

General settings

  • Dark mode switches between light and dark themes.

Viewers do not see settings on a shared timer link. To change dark mode, open your own timer, switch Dark mode, then return to the shared link. The choice stays on your device and does not affect anyone else.

Share the timer

  • Copy the timer link from settings.
  • Anyone with the link can view the timer live.
  • Only the person who created the timer can control it.

You can create only one timer per device at a time. If you need a second timer, use another device or browser.

Sounds

  • A short ding plays when you start or resume.
  • Dings play for the last five seconds.
  • A dong plays when the phase changes.
